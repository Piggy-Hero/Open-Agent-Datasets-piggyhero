# PMO-Agent-Vibe-Coding Dataset

This folder contains the open-source demo dataset extracted from a real-world, 1200+ step pair-programming session. 

## 🚀 What is this?
This dataset captures how a human architect and an AI Agent collaborated to build a complex, production-ready SaaS frontend (an Intelligent PMO Hub) from scratch. It includes real-world debugging, self-correction loops, and architecture refactoring.

## 📂 Folder Contents
*   `bug_fix_demo.jsonl`: 8 raw samples of high-value multi-step reasoning and self-correction traces.
*   `README.md`: Detailed dataset card (includes YAML Front Matter for Hugging Face).
*   `LICENSE`: CC BY-NC 4.0 (Strictly for academic/personal use, no commercial use).
*   `_reports/`: Bilingual sanitization and quality control reports.
